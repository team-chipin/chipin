# Chipin, Mobile application for debt management in group trips

## Description
Chipin is a mobile app designed for managing debts in group trips. The app allows users to create a group, 
where friends can join before the trip. 
Users can then add transactions to record who paid for whom in places like restaurants, museums, hotels, etc. 
The application calculates all debts (including currency conversion if the trip is to a country with a different currency) 
and clearly shows who owes money and who must pay after returning home.
